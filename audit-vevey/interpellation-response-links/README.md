# Rapprochement des interpellations et réponses de Vevey

Le rapprochement utilise les interpellations canoniques et les vraies réponses
municipales détectées dans la rubrique Annexes.

- 25 réponses municipales ;
- 21 correspondances exactes ;
- 4 réponses à vérifier manuellement ;
- aucune relation incertaine n'est créée automatiquement.

Les fiches de `metadata/` décrivent les réponses avec le même contrat que
La Tour-de-Peilz. Les fiches de `political_objects/` reprennent les
interpellations et renseignent `political_status=response_available`,
`interpellation_metadata.responses` et les identifiants de réponse lorsqu'une
correspondance exacte existe.

Ouvrir `index.html` pour examiner les correspondances et `links.json` pour le
résultat technique.
